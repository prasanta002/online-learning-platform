# 🎓 EduLearn – Online Learning & Course Management Platform

EduLearn is a Django-based online learning platform where students can browse courses, enroll in courses, watch lessons, track their learning progress, and receive certificates after completing courses.

## 🚀 Features

### 👨‍🎓 Student
- User registration and login
- Profile management
- Browse courses
- Free course enrollment
- Paid course enrollment
- Razorpay payment integration
- My Courses
- Video lessons
- Lesson completion tracking
- Course progress tracking
- Course certificates
- Payment history
- Password change
- Password reset

### 👨‍💼 Officer / Instructor
- Officer login
- Create courses
- Edit courses
- Delete courses
- Add lessons
- Upload lesson videos
- Edit lessons
- Delete lessons
- Manage students
- Track student progress
- View payment information
